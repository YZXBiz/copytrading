# Code of Conduct

We want project discussions to be useful and respectful. Participate in good faith, focus criticism on ideas and code, and make room for different experience levels and backgrounds.

Harassment, discrimination, threats, personal attacks, and posting another person's private information are not acceptable. Keep credentials, private source messages, account data, and security details out of public project spaces.

For a conduct concern, report it privately to the maintainer through [GitHub's private reporting](https://github.com/YZXBiz/copytrading/security/advisories/new) and start the title with "Conduct". The maintainer will review reports and may remove content or limit participation when needed.
