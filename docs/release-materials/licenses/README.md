# Supplied license texts

Some bundled Python distributions declare a license in their metadata but ship no license
file. Their text is supplied here, one directory per `<normalized-name>-<version>`, taken
from the upstream repository at the matching release tag. A version bump finds no directory
and the release reports the distribution as missing license material again until the text
is checked and supplied for the new version.
